Instalar app

App de Calibración de Boquillas para Android.

La APK es para celulares Android: abra esta página desde el celular para instalarla.

  1. Toque Descargar e instalar. Si Chrome avisa que el archivo puede ser dañino, toque Descargar de todas formas.
  2. Al terminar, toque Abrir en el aviso de descarga: se abre el instalador de Android.
  3. Si lo pide, active “Permitir de esta fuente” para Chrome y regrese.
  4. Toque Instalar. Si aparece Play Protect, toque Más detalles › Instalar de todas formas.

Ya instalada, la app se actualiza sola: cuando haya una versión nueva le preguntará si desea instalarla.
